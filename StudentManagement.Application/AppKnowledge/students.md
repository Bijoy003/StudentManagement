# Students Module

## Location

Navigate to **Students** in the top menu.

## Features

### Student list

- Displays all students in a searchable/sortable grid (DataTables).
- Columns: ID, Name, Email, Phone, Address, Date of Enrollment.

### Create or edit a student

- Click create or select a row and edit.
- Required fields: Name, Email.
- Optional: Phone, Address, Date of Enrollment.

### Delete a student

- Select a student from the grid and use the delete action.

### Report: Students enrolled in more than N courses

- Available from the Students page via **Show Students enrolled**.
- Enter a course count threshold to find students enrolled in more than that many courses.

## Chat data tools

When users ask about students, the assistant can call tools to list students, look up a student by ID, or find students enrolled in more than a given number of courses.

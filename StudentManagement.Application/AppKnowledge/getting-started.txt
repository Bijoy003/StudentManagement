Getting Started with Student Management

This guide will help you get up and running with the Student Management application.

System Requirements

The application requires a modern web browser and an internet connection. For administrators, a stable network connection is recommended for managing users and viewing reports.

Installation and Setup

The application is deployed as a web service. Users access it through their browser at the provided URL. No local installation is required.

Administrators should ensure that the database is properly configured and that email services are set up for password reset and notification features.

First-Time Login

Navigate to the application URL in your browser. Click the Login button and enter the credentials provided by your system administrator. If Google OAuth is enabled, you can also sign in with your Google account.

After logging in, you will see the main navigation menu with links to Students, Courses, Enrollments, and Chat.

Using the Chat Assistant

The chat assistant is an AI-powered tool that can answer questions about the application and retrieve live data from the system. You can ask questions like "How many students are enrolled?" or "Show me courses with more than 5 students."

The assistant uses function tools to query the database directly, so answers are always based on current data.

Troubleshooting
